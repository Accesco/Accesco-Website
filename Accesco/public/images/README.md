# Images Folder

Place your video thumbnails and video files in this folder with the following names:

## Required Files:

### Video Thumbnails:
- `about-us-thumbnail.jpg` - Thumbnail for "About US" video
- `delivery-process-thumbnail.jpg` - Thumbnail for "Delivery Process Overview" video

### Video Files:
- `about-us-video.mp4` - Video file for "About US"
- `delivery-process-video.mp4` - Video file for "Delivery Process Overview"

## Optional Files:

### Logo and Hero:
- `logo.png` - Company logo (if you want to replace the gradient placeholder)
- `hero-background.jpg` - Hero section background image or video

---

**Note:** The application is currently configured to use these exact file names from the `public/images` folder. Make sure your files match these names, or update the file paths in `/app/page.tsx` if you use different names.
